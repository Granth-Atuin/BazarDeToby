# Bazar de Toby

Tienda online hecha en React, con catálogo por categorías, carrusel de productos, buscador y carrito. Fue un trabajo de Desarrollo Web 2 (Tecnicatura en Desarrollo Web y Aplicaciones, UNTDF).

## Funcionalidades

- Productos y categorías traídos desde una API REST.
- Carrusel de destacados y carrusel de categorías.
- Buscador en la barra de navegación.
- Ficha de detalle de cada producto.
- Carrito lateral con estado global.

## Tecnologías

- React 18 y React Router
- Zustand para el estado del carrito
- Tailwind CSS
- Vite

## Cómo correrlo

```bash
cd bazar-de-toby
npm install
npm run dev
```

Después abrí http://localhost:5173.
